# Project Controls Dashboard

**▶ Use it free:** https://sara-mostafshar.github.io/project-controls-dashboard/ · **🎥 Video (3 min):** https://youtu.be/Gl09r2QoJ2w · **📦 Sample data:** [4 months](https://sara-mostafshar.github.io/project-controls-dashboard/project-controls-dashboard-with-sample-data.zip)

Turn your monthly Excel cost report and Primavera P6 schedule into a project dashboard – no Power BI needed.

- Progress, budget used, SPI and CPI – with the source cell and formula under every number
- Automatic data quality checks
- Month-by-month tracking, timeline and month vs month comparison
- Critical path, Gantt chart, budget by phase and open issues
- Print / PDF, backup export and import

## How to use
1. Download the sample data (8 files, Sep–Dec 2025) and unzip it.
2. Open the dashboard and drag all 8 files onto the page.
3. Use the month selector to move between months.

To use your own data, see *HOW TO USE.txt* inside the sample-data zip.

🔒 Files are read in your browser only; stored months stay in your browser. The sample project (RBHP) is fictional.
